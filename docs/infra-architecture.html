보안 설정 요약
1
HTTPS 적용 — LB에서 Google 관리형 인증서로 TLS 종단, HTTP(80)는 301로 HTTPS 강제
2
방화벽 — 외부 공개는 LB 80·443뿐(Cloud Run 직접 접근 차단). VPC의 SSH(22)·RDP(3389)·ICMP 전체 허용 규칙 삭제, VM 없음
3
DB 포트 비노출 — Cloud SQL Public IP 미할당, 3306은 VPC 사설망(Cloud Run Direct VPC egress)에서만 접근
4
민감정보 관리 — DB 접속정보는 Secret Manager, CI는 WIF 키리스 인증. 레포·이미지·GitHub Secrets에 비밀값 없음
5
WAS / DB 분리 — WAS는 Cloud Run, DB는 관리형 Cloud SQL로 분리. 서비스 계정 최소 권한 분리 (런타임 / 배포)
✓
CI/CD — develop: 빌드·테스트 / main: 테스트 → 빌드 → 배포 → 헬스체크 자동화 (무중단 리비전 전환)
