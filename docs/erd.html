제약 · 규칙

  • 외부 노출 ID 분리: API는 public_id(ULID)만 사용, 내부 id(BIGINT)는 노출하지 않음
  • 좋아요 · 참여 중복 방지: UK(routine_id, user_id) — 취소는 행 삭제 대신 deleted_at, 다시 누르면 같은 행 복구
  • 스텝 순서: UK(routine_id, sort_order) + CHECK(sort_order BETWEEN 1 AND 10)
  • 참여 상태: IN_PROGRESS → COMPLETED, 작성자 본인 참여는 API에서 차단
  • 이미지: 오브젝트 스토리지 없이 images.data MEDIUMBLOB에 저장 (최대 10MB)
  • 감사 컬럼: created_by / updated_by / deleted_by는 작업한 users.id 기록용 (FK 미설정)
  • 랭킹 스냅샷: 좋아요순 · 참여순 커서용 임시 데이터로 다른 테이블과 FK 없이 public_id로만 참조
